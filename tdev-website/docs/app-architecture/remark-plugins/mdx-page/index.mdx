# MDX Page

Dieses Plugin ermöglicht Seitenbasierte Zusammenfassungen (wie die TaskStateSummary) und dynamische Inhalte wie bspw. Kommentare. Es fügt jeder Seite mit einer `page_id` im Frontmatter eine Komponente `<MdxPage pageId={...} />` mit der `pageId` als Attribut hinzu. Die Komponente selbst hat keinen visuellen Output und dient 

## Installation

:::info[Code]
- `src/plugins/remark-page`
- `src/components/MdxPage`
- `src/hooks/useDocumentRoot.ts`

und, falls nicht bereits vorhanden:
- `src/stores/pageStore.ts`inkl. dessen Registrierung im RootStore.
- `src/models/Page.tsx`
:::

Das Plugin ist als `pagePluginConfig` in den `recommendedRemarkPlugins` aus `src/siteConfig/markdownPluginConfigs.ts` enthalten. Websites ohne eigene `remarkPlugins` im `siteConfig.ts` erhalten es damit automatisch. Das Plugin hat keine Optionen.

:::warning[Eigene Plugin-Liste]
Bei einer eigenen Plugin-Liste muss `pagePluginConfig` darin enthalten sein:

```ts title="siteConfig.ts"
import { pagePluginConfig } from '../src/siteConfig/markdownPluginConfigs';

const getSiteConfig: SiteConfigProvider = () => ({
    remarkPlugins: [
        /* ... */
        pagePluginConfig
    ]
});
```
:::
