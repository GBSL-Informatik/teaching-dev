# Enumerate Components

Dieses Remark-Plugin fügt spezifizierten Komponenten das Attribut `pagePosition` hinzu. `pagePosition` ist eine simple, inkrementelle Nummerierung der entsprechenden Komponenten und ermöglicht es client-seitig die Reihenfolge der Komponenten zu bestimmen.

Im foglenden Beispiel ist der Effekt zu sehen, wenn die beiden Komponenten `<Answers />` und `<TaskState />` nummeriert werden.

:::flex{minWidth=250px}
#### Vorher
```md
# Remark Enumerate Components

<Answers />

## Foo Bar
<ComponentFoo />

Lorem ipsum dolor sit amet,
<TaskState />

consectetur adipiscing elit.
<Answers />

```
::br
#### Nachher
```md
# Remark Enumerate Components

<Answers pagePosition={1} />

## Foo Bar
<ComponentFoo />

Lorem ipsum dolor sit amet,
<TaskState pagePosition={2} />

consectetur adipiscing elit.
<Answers pagePosition={3} />

```
:::



## Installation

:::info[Code]
- `src/plugins/remark-enumerate-components`
:::

Das Plugin ist in den `recommendedRemarkPlugins` aus `src/siteConfig/markdownPluginConfigs.ts` enthalten. Websites ohne eigene `remarkPlugins` im `siteConfig.ts` nummerieren damit standardmässig `Answer`, `TaskState` und `ProgressState`.

## Optionen

`componentsToEnumerate`
: Namen der Komponenten, die eine `pagePosition` erhalten.
: Standard der `recommendedRemarkPlugins`: `['Answer', 'TaskState', 'ProgressState']`.

## Weitere Komponenten nummerieren

Um weitere Komponenten zu nummerieren (z.B. aus einem Package), wird im `siteConfig.ts` die Standardkonfiguration des Plugins durch eine erweiterte ersetzt:

```ts title="siteConfig.ts"
import type { Pluggable } from 'unified';
import enumerateAnswersPlugin from '../src/plugins/remark-enumerate-components/plugin';
import {
    enumerateAnswersPluginConfig,
    enumerateAnswersPluginOptions,
    recommendedRemarkPlugins
} from '../src/siteConfig/markdownPluginConfigs';

const extendedEnumerateAnswersPluginConfig = [
    enumerateAnswersPlugin,
    {
        // highlight-next-line
        componentsToEnumerate: [...enumerateAnswersPluginOptions.componentsToEnumerate, 'MyComponent']
    }
] satisfies Pluggable;

const remarkPlugins = recommendedRemarkPlugins.map((plugin) =>
    plugin === enumerateAnswersPluginConfig ? extendedEnumerateAnswersPluginConfig : plugin
);

const getSiteConfig: SiteConfigProvider = () => ({
    remarkPlugins: remarkPlugins
});
```

:::warning[Eigene Plugin-Liste]
Die Ersetzung greift nur, wenn die Liste die unveränderte `enumerateAnswersPluginConfig` enthält. Bei einer eigenen Plugin-Liste muss das Plugin mit den gewünschten `componentsToEnumerate` direkt eingetragen werden.
:::
