# Tabs

Docusaurus stellt standardmässig [Tab-Komponenten](https://docusaurus.io/docs/markdown-features/tabs) zur Verfügung:

<CodeShowcase imports={[`import Tabs from '@theme/Tabs';`, `import TabItem from '@theme/TabItem';`]}>
<Tabs>
  <TabItem value="apple" label="Apple" default>
    This is an apple 🍎
  </TabItem>
  <TabItem value="orange" label="Orange">
    This is an orange 🍊
  </TabItem>
  <TabItem value="banana" label="Banana">
    This is a banana 🍌
  </TabItem>
</Tabs>
</CodeShowcase>

Weitere Optionen und Anpassungen sind in der [Docusaurus-Dokumentation](https://docusaurus.io/docs/markdown-features/tabs) beschrieben.
