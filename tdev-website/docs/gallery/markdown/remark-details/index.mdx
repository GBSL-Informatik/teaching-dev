# Details

In Docusaurus werden html-details hübsch dargestellt. Hier ein Beispiel:

<CodeShowcase lang="md">
<details>
    <summary>
        Mehr zu meinen **Sommerferien** 🍹
    </summary>
    ☀️⛰️🏖️🏝️
</details>
</CodeShowcase>

Um die Details mit weniger Aufwand zu erstellen, können auch `:::details`-Blöcke verwendet werden:

<CodeShowcase lang="md">
:::details[Mehr zu meinen **Sommerferien** 🍹]
☀️⛰️🏖️🏝️
:::
</CodeShowcase>

...mit demselben Resultat.

## Optionen

## Farben

Wie bei den Admonitions kann die Farbe über eine Klasse gewählt werden. Ohne Klasse sind Details blau (`info`).

<CodeShowcase lang="md">
:::details[Achtung, Lösung! 🚨]{.danger}
Nicht zu früh aufklappen.
:::

:::details[Tipp 💡]{.tip}
Zuerst die Aufgabenstellung genau lesen.
:::

:::details[Zusatzaufgabe]{.orange}
Für alle, die schon fertig sind.
:::
</CodeShowcase>

Folgende Klassen sind verfügbar:

`.primary`, `.secondary`, `.success`, `.info`, `.warning`, `.danger`
: Die Farben der Infima-Alerts.
`.note`, `.tip`, `.caution`
: Dieselbe Farbe wie die gleichnamige Admonition (`secondary`, `success` bzw. `warning`).
`.red`, `.orange`, `.green`, `.lightBlue`, `.gray`, `.grey`, `.black`
: Dieselben Farbnamen wie bei Buttons: `danger`, `warning`, `success`, `info`, `secondary` bzw. `primary`.
`.blue`
: Blau (`--ifm-color-blue`), unabhängig von der Primärfarbe der Website.

## Installation

:::info[Code]
- `src/plugins/remark-details`
- `src/components/shared/Colors/infimaTypes.ts`
- `.alert--*`-Regeln in `src/css/custom.scss`
:::

Das Plugin ist als `detailsPluginConfig` in den `recommendedBeforeDefaultRemarkPlugins` aus `src/siteConfig/markdownPluginConfigs.ts` enthalten. Websites ohne eigene `beforeDefaultRemarkPlugins` im `siteConfig.ts` erhalten es damit automatisch.

## Konfiguration

`colors`
: Weitere Klassen, die eine Farbe setzen. Bestehende Klassen können damit auch umgefärbt werden.
: Werte: `primary`, `secondary`, `success`, `info`, `warning`, `danger` oder `blue`.

Um eigene Farb-Klassen zu ergänzen, wird im `siteConfig.ts` die Standardkonfiguration des Plugins ersetzt:

```ts title="siteConfig.ts"
import type { Pluggable } from 'unified';
import detailsPlugin from '../src/plugins/remark-details/plugin';
import {
    detailsPluginConfig,
    recommendedBeforeDefaultRemarkPlugins
} from '../src/siteConfig/markdownPluginConfigs';

const coloredDetailsPluginConfig = [
    detailsPlugin,
    {
        // highlight-next-line
        colors: { purple: 'primary', exam: 'danger' }
    }
] satisfies Pluggable;

const getSiteConfig: SiteConfigProvider = () => ({
    beforeDefaultRemarkPlugins: recommendedBeforeDefaultRemarkPlugins.map((plugin) =>
        plugin === detailsPluginConfig ? coloredDetailsPluginConfig : plugin
    )
});
```

:::warning[Eigene Plugin-Liste]
Die Ersetzung greift nur, wenn die Liste die unveränderte `detailsPluginConfig` enthält. Bei einer eigenen Plugin-Liste muss das Plugin mit den gewünschten `colors` direkt eingetragen werden.
:::
