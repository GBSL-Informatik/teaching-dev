# Admonitions

Als Erweiterung der Standard-Markdown-Syntax werden sog. [Admonitions](https://docusaurus.io/docs/markdown-features/admonitions), also Hinweise, die durch das Einrahmen von Text mit drei Doppelpunkten und einem Label, das den Typ angibt, erstellt werden.

<CodeShowcase lang="md">
:::note
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::

:::aufgabe
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::

:::info
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::

:::tip
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::

:::definition
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiternungen__.
:::

:::warning
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::

:::danger
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::


:::insight
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::

</CodeShowcase>

## Titel anpassen

Der Titel der Admonition kann durch Hinzufügen von Text nach dem Admonition-Typ angepasst werden:

<CodeShowcase lang="md">
:::info[Anpassung des `Titels`]
Beliebiger **Inhalt** mit *Markdown* `Syntax`, inkl. __Erweiterungen__.
:::
</CodeShowcase>

## Verschachtelte Admonitions

Admonitions basieren auf dem [remark-directives](https://github.com/remarkjs/remark-directive). Der entsprechende Parser unterstützt Verschachtelungen wie folgt:

<CodeShowcase lang="md">
:::::warning[Wichtiger Hinweise]
Wichtige Hinweise zu beachten:
::::info[Erster Hinweis]
Dies ist der erste Hinweis.
:::tip[Bemerke]
Jede Verschachtelungsebene hat einen zusätzlichen Doppelpunkt `:`.
:::
::::
:::danger[Zweiter Hinweis]
Die Übersichtlichkeit leidet 😅🥸🫣.
:::
:::::
</CodeShowcase>

## Admonitions in Listen

Um Admonitions in Listen zu verwenden, muss die Einrückung korrekt sein.

<CodeShowcase lang="md">
- Erster Punkt
  :::info
  Dies ist eine Admonition in einer Liste.
  :::
- Zweiter Punkt
    1. Mit Unterliste
    2. und Admonition
       :::tip
       Dies ist eine Admonition in einer Unterliste.
       :::
    3. Weiter im Text
- Dritter Punkt

</CodeShowcase>

## Weitere Admonition-Typen

:::info[Weitere Admonition-Typen]
In den meisten Installationen von tdev sind die folgenden zusätzlichen Admonition-Typen ebenfalls verfügbar:
- `:::definition`
- `:::finding`
- `:::insight`
- `:::aufgabe`
:::
