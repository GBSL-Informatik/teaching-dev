# ::youtube

Fügt ein YouTube-Video ein.

## Optionen

`height`
: Höhe des Videos.
: Standardmässig nicht gesetzt, dann wird das __16 / 9__ Breitbildformat verwendet.
: z.B. `height=200px`
`width`
: Breite des Videos, wobei die `max-width` standardmässig auf `100%` gesetzt ist.
: z.B. `width=200px`
