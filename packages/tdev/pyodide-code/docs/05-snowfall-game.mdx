# Schneefall-Spiel

Mit `@gameloop` aktualisiert Python eine Szene regelmässig und verarbeitet dabei Browser-Ereignisse. Klicke auf eine Schneeflocke, um sie zu entfernen.

<CodeShowcase lang="md" imports={[`import SnowfallGame from '@tdev/pyodide/snowfall-game/Component';`]}>
<SnowfallGame sceneId="snowfall" />

```py live_pyo id=8ee3ce4d-6f41-43e4-afd8-17da3141e3d6 title=Schneefall
from random import randint
from webio import gameloop, run
from snowfall_game import use_scene

scene = use_scene('snowfall')
scene.reset()
scene.configure(width=400, height=800, background_color='black')
scene.render()
last_spawn_time = -1000

def spawn_snowflake():
    x = randint(0, int(scene.width))
    size = randint(2, 5)
    speed = randint(40, 100)
    scene.add_snowflake(x, 0, size, speed)

def update_snowflakes(dt):
    for snowflake in scene.snowflakes:
        snowflake.y += snowflake.speed * dt
        if snowflake.y > scene.height:
            scene.remove_snowflake(snowflake)

def handle_click(event):
    for snowflake in scene.snowflakes:
        distance_squared = (snowflake.x - event.x)**2 + (snowflake.y - event.y)**2
        if distance_squared < (snowflake.size + 10)**2:
            scene.remove_snowflake(snowflake)
            break

@gameloop(fps=30, sources=[scene])
def update(ctx):
    global last_spawn_time
    if ctx.time - last_spawn_time >= 1000:
        spawn_snowflake()
        last_spawn_time = ctx.time

    update_snowflakes(ctx.dt)

    for event in ctx.events:
        if event.type == 'click':
            handle_click(event)

    scene.render()

await run()
```
</CodeShowcase>

Die Geschwindigkeiten sind in Pixeln pro Sekunde angegeben. `ctx.dt` berücksichtigt die tatsächlich vergangene Zeit zwischen zwei Bildern. `scene.render()` überträgt alle Änderungen eines Bildes gemeinsam an den Browser. Details zum Ablauf stehen in der [webio-Referenz](./02-webio.mdx#spielschleife).

## Szene und Schneeflocken

`sceneId`
: Verbindet die React-Komponente mit `use_scene(id)`. Mehrere Ansichten derselben ID teilen ihre Anzeige.
`use_scene(id)`
: Liefert innerhalb derselben Ausführung denselben lokalen Handle zurück.
`configure(width=400, height=800, background_color='black')`
: Legt die logische Grösse und Hintergrundfarbe fest. Die Darstellung verkleinert sich bei wenig Platz proportional; Spielkoordinaten bleiben unverändert.
`width`, `height`
: Logische Breite und Höhe der Szene in Pixeln.
`reset()`
: Entfernt alle Schneeflocken und behält die Konfiguration bei.
`add_snowflake(x, y, size, speed)`
: Erzeugt eine Schneeflocke und gibt ihren Handle zurück. `size` ist der Radius in Pixeln. Die Bewegung mit `speed` legt der Python-Code fest.
`snowflakes`
: Momentaufnahme der aktuellen Schneeflocken. Während der Iteration können Schneeflocken entfernt werden.
`snowflake.x`, `snowflake.y`, `snowflake.size`, `snowflake.speed`
: Veränderbare Eigenschaften einer Schneeflocke. Die Position und Grösse werden beim nächsten `render()` sichtbar.
`remove_snowflake(snowflake)`
: Entfernt die angegebene Schneeflocke.
`render()`
: Überträgt den aktuellen Zustand der ganzen Szene. Änderungen an Handles, `configure()` und `reset()` werden erst damit sichtbar.
`events`
: Ereignisquelle für `@gameloop`, `@on_click` und weitere Handler aus `webio`.

Klick-Ereignisse enthalten `event.x` und `event.y` in logischen Szenenkoordinaten, auch bei verkleinerter Darstellung. Dieselben Werte stehen in `event.payload['x']` und `event.payload['y']`. Tastatureingaben gehen an die fokussierte Szene und enthalten den Tastennamen in `event.payload['key']`.

## Zustand und Lebensdauer

Die Browser-Anzeige bleibt nach Ende oder Abbruch eines Skripts erhalten. Ein neuer Python-Handle beginnt mit den Standardwerten und ohne Schneeflocken. Sein erster `render()` ersetzt die bisherige Anzeige. Mit `reset()` und `configure()` am Skriptanfang lässt sich der gewünschte Startzustand ausdrücklich festlegen.

## Auf der eigenen Website einrichten

Voraussetzung ist das [installierte Pyodide-Package](./README.mdx#installation).

<Steps>

1. Kopiere den vollständigen Ordner [snowfall-game](https://github.com/GBSL-Informatik/teaching-dev/tree/main/tdev-website/website/pyodide/snowfall-game) nach __website/pyodide/snowfall-game__.
2. Ergänze den Ordner in der bestehenden `extensions`-Liste des [Pyodide-Plugins](./README.mdx#erweiterungen-registrieren):

    ```ts title="siteConfig.ts"
    extensions: [
        './website/pyodide/snowfall-game'
    ]
    ```

3. Starte den Entwicklungsserver neu. Danach kannst du das MDX-Beispiel oben verwenden.

</Steps>

Die __extension.json__ im kopierten Ordner legt den Namen und die Einstiegspunkte fest. Der Browser-Store wird automatisch initialisiert; der `SiteStore` deiner Website benötigt keine Ergänzungen.
