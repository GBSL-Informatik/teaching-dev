# Interaktive Uhr

Python steuert die Zeiger einer React-Komponente. Alle Winkel sind in Grad angegeben.

<CodeShowcase lang="md" imports={[`import Clock from '@tdev/pyodide/clock/src/components/Clock';`]}>
<Clock clockId="sbb-uhr" />

```py live_pyo id=e63340b1-3821-4b70-99af-602272a48d8d title=Interaktive_Uhr
from clock import use_clock
from time import sleep
uhr = use_clock("sbb-uhr")

while True:
    uhr.set_seconds(uhr.seconds + 1)
    if uhr.seconds % 360 == 0:
        sleep(0.99)
        uhr.set_minutes(uhr.minutes + 6)
        if uhr.minutes % 360 == 0:
            uhr.set_hours(uhr.hours + 30)
    sleep(0.01)
```
</CodeShowcase>

## Auf der eigenen Website einrichten

Voraussetzung ist das [installierte Pyodide-Package](./README.mdx#installation).

<Steps>

1. Kopiere den vollständigen Ordner [clock](https://github.com/GBSL-Informatik/teaching-dev/tree/main/tdev-website/website/pyodide/clock) nach __website/pyodide/clock__. Er enthält Komponenten, Styles, Browser-Store und Python-Modul.
2. Ergänze den Ordner in der bestehenden `extensions`-Liste des [Pyodide-Plugins](./README.mdx#erweiterungen-registrieren):

    ```ts title="siteConfig.ts"
    extensions: [
        './website/pyodide/clock'
    ]
    ```

3. Starte den Entwicklungsserver neu. Danach kannst du das MDX-Beispiel oben verwenden.

</Steps>

Die __extension.json__ im kopierten Ordner legt den Namen und die Einstiegspunkte fest. Der Browser-Store wird automatisch initialisiert; der `SiteStore` deiner Website benötigt keine Ergänzungen.

## Aufbau der Erweiterung

Die Uhr verwendet die allgemeine [Erweiterungs-API](./README.mdx#eigene-erweiterungen-weitergeben). Nachrichtentypen, Worker, Browser-Store und React-Komponente liegen gemeinsam im kopierbaren Ordner.

### Gemeinsamer Nachrichtentyp

```ts title="website/pyodide/clock/protocol.ts"
export interface ClockTime {
    hours: number;
    minutes: number;
    seconds: number;
}

export type ClockUpdate = Partial<ClockTime>;
```

Eine Nachricht kann einzelne Zeiger oder die ganze Uhr ändern. Worker und Browser-Handler verwenden `ClockUpdate` als Typparameter.

## Python-Handle

`use_clock(id)`
: Verbindet den Handle mit der `clockId` der React-Komponente. Jeder Aufruf erzeugt einen eigenen Handle mit lokalen Nullwerten.
`hours`, `minutes`, `seconds`
: Lesen die letzten Winkel dieses Handles, nicht den Browser-Store oder andere Handles.
`set_hours(winkel)`, `set_minutes(winkel)`, `set_seconds(winkel)`
: Ändern jeweils nur den zugehörigen Zeiger im Browser.
`set_time(stunden, minuten, sekunden)`
: Setzt alle drei Zeiger. Die Argumente sind Winkel in Grad.
`reset()`
: Setzt alle Zeiger auf null.

## Zustand und Lebensdauer

Mehrere Komponenten mit derselben `clockId` teilen den Zustand im Browser-Store. Dieser bleibt nach Ende oder Abbruch eines Skripts erhalten; ein Neustart setzt ihn nicht automatisch zurück. Ein unbekanntes Ziel wird beim ersten Update im `ClockStore` angelegt, auch wenn noch keine React-Komponente dafür angezeigt wird.

Ein neuer Python-Handle beginnt dagegen wieder bei null und verändert die Anzeige erst mit seinem ersten Update. Die Erweiterung bietet keine Rückfragen vom Browser an Python.

Für Hilfsmodule, die Handles oder Factory-Referenzen speichern, gelten die Hinweise zur [Wiederverwendung von Workern](./README.mdx#zustand-und-lebensdauer).
