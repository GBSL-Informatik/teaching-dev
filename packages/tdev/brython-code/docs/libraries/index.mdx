# Bibliotheken

Alle Python-Files, die in `static/bry-libs` liegen, können in deinem Code importiert werden. Sie sind bereits im Browser verfügbar. Solange es sich um reine Python-Bibliotheken handelt, können sie direkt von Brython ausgeführt werden.

:::warning[Hinweis]
Bibliotheken, die auf C-Extensions angewiesen sind, können nicht direkt im Browser ausgeführt werden.
:::
