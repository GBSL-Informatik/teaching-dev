# github-cms

:::warning[WIP 🚧]
Dieses Feature ist ein Work in Progress. Es funktioniert weitgehend, kann aber noch Fehler enthalten.
Es wird von [hfr](https://github.com/lebalz) entwickelt und ist noch nicht ein offizielles package.
:::

## Installation

:::info[`siteConfig.ts`]
```ts
import githubCmsPlugin from '../packages/hfr/github-cms/plugin';

export default {
    // ...
    showEditThisPageOptions: [/*...*/, 'cms'],
    plugins: [
        // ...
        githubCmsPlugin({
            /**
             * use the same configs as specified in your SiteConfig,
             * except for `SiteConfig.pages.path`
            */
            pages: {},
            remarkPlugins: recommendedRemarkPlugins,
            rehypePlugins: recommendedRehypePlugins,
            beforeDefaultRemarkPlugins: recommendedBeforeDefaultRemarkPlugins
        })
    ],
    dynamicRoutes: [
        // ...
        {
            path: '/cms/',
            component: '@hfr/github-cms/components'
        }
    ],
    apiDocumentProviders: [
        // ...
        require.resolve('@hfr/github-cms/register')
    ]
};

```
:::
## CMS einer anderen Website verwenden

Websites ohne dieses Package können die «cms»-Links auf das CMS einer anderen Teaching-Dev-Website zeigen lassen. Dort muss man sich mit einem GitHub-Konto anmelden, das Zugriff auf das Repository dieser Website hat.

:::info[`siteConfig.ts`]
```ts
export default {
    // ...
    showEditThisPageOptions: [/*...*/, 'cms'],
    editThisPageCmsUrl: 'https://teaching-dev.gbsl.website/cms/',
    // optional: Links zum CMS immer in einem neuen Tab öffnen.
    // Standard: Links auf andere Websites öffnen in einem neuen Tab.
    editThisPageCmsNewTab: true
};
```
:::
